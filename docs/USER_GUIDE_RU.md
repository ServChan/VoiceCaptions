## Что делает мод

Voice Captions показывает, что говорят другие игроки в голосовом чате [Plasmo Voice](https://modrinth.com/mod/plasmo-voice): распознанный текст появляется «облаком» над головой говорящего, как субтитры.

Мод берёт уже декодированный голос из Plasmo Voice, режет его на фразы и отдаёт локальному движку Whisper. Распознавание идёт на вашем компьютере: на видеокарте или на NPU ноутбука с Ryzen AI. Никакие облачные сервисы не используются.

Это полезно, если вы плохо слышите, играете без звука, не понимаете быстрой речи или хотите видеть, кто именно говорит в толпе.

## Что нужно

- Minecraft 26.3 с Fabric Loader `0.19.3+` и Fabric API `0.161.0+26.3`.
- [Plasmo Voice](https://modrinth.com/mod/plasmo-voice) `2.1.17` или новее для 26.3 — у вас и на сервере.
- Java 25.
- Чем распознавать, одно из:
  - **видеокарта** с поддержкой Vulkan (NVIDIA, AMD или Intel) на Windows x64 — мод сам скачает и запустит движок;
  - **NPU** ноутбука с Ryzen AI 300 (например, HX 370) и программа FastFlowLM;
  - **свой сервер** распознавания с API `/v1/audio/transcriptions`.

## Установка

1. Установите Fabric Loader, Fabric API и Plasmo Voice для 26.3.
2. Положите в `mods` файл `voice-captions-1.1.1.jar` (как собрать — в разделе [Сборка](#сборка-из-исходников)).
3. Необязательно: [Mod Menu](https://modrinth.com/mod/modmenu).
4. Запустите игру и выберите движок (следующий раздел).

## Выбор движка распознавания

По умолчанию стоит режим **«Авто»**: мод сам выбирает, чем распознавать.

1. Если на компьютере запущен NPU-сервер FastFlowLM, речь идёт на NPU. Процессор и видеокарта остаются игре.
2. Иначе мод запускает Whisper на видеокарте, если движок уже скачан.
3. Если NPU-сервер закрыли посреди игры, следующая фраза сама уходит на видеокарту.

### Видеокарта (рекомендуется для большинства)

1. Введите в чате `/voicecaptions` — откроются настройки.
2. Вкладка **«Распознавание»** → кнопка **«Скачать для видеокарты»**.
3. Мод скачает whisper.cpp 1.8.4 с Vulkan (около 21 МБ, с GitHub `lemonade-sdk`) и модель (с Hugging Face `ggerganov`), проверит размер и SHA-256 и распакует в папку `voicecaptions/` игры.
4. Дальше движок запускается сам при входе в мир и сразу «прогревается», чтобы первая фраза не ждала 5–8 секунд сборки шейдеров Vulkan.

Если у вас прокси, мод учитывает системный прокси Windows и переменные окружения `HTTPS_PROXY` и `HTTP_PROXY`.

Модели для видеокарты:

| Модель | Размер | Видеопамять | Фраза 3–7 с (RTX 5080) | Русский язык |
|---|---|---|---|---|
| Turbo (по умолчанию) | 547 МБ | около 0,9 ГБ | 60–120 мс | без ошибок на тестовых фразах |
| Small | 181 МБ | не замерялась | не замерялась | между Turbo и Base |
| Base | 57 МБ | не замерялась | 30–55 мс | заметно ошибается |

Модель меняется настройкой «Модель» на вкладке «Распознавание». Новую модель нужно скачать той же кнопкой.

### NPU (ноутбуки с Ryzen AI 300)

1. Обновите драйвер NPU AMD до `32.0.203.311` или новее (Диспетчер устройств → Нейронные процессоры).
2. Установите FastFlowLM: `flm-setup.msi` со страницы [релизов](https://github.com/ROCm/FastFlowLM/releases).
3. В терминале выполните:

   ```powershell
   flm pull whisper-v3:turbo
   flm serve --asr 1
   ```

4. Сервер слушает `127.0.0.1:52625`. Режим «Авто» находит его сам и предпочитает видеокарте.

Первая фраза после запуска сервера распознаётся 10–15 секунд, пока грузится модель, дальше короткая фраза — примерно 1–2,5 секунды. FastFlowLM сам определяет язык и не смотрит на настройку «Язык».

### Свой сервер

1. Переключите «Движок» на **«Свой сервер»**.
2. Укажите «Адрес сервера», например:
   - Lemonade Server: `http://127.0.0.1:13305/v1/audio/transcriptions`;
   - `whisper-server` из whisper.cpp: `http://127.0.0.1:8080/inference`.
3. Укажите «Модель», если её требует сервер (whisper.cpp её не смотрит).

В этом режиме речь уходит только на указанный адрес.

## Первая проверка

1. `/voicecaptions check` или кнопка «Проверить сервер» — мод сохранит настройки, отправит движку секунду тишины и напишет, какой движок ответил и за сколько.
2. `/voicecaptions test Привет, это проверка` — облако появится над ближайшим игроком, а если рядом никого нет, над вами (посмотрите через F5).
3. Позовите друга в голосовой чат и попросите что-нибудь сказать.

Если распознавать нечем, мод пишет в чат одну понятную подсказку (не чаще раза в минуту) и делает паузу, а не засыпает сервер запросами.

## Как выглядят субтитры

- Облако привязано к игроку, движется вместе с ним и плавно уменьшается с расстоянием.
- Текст переносится по словам, слишком длинное слово разбивается с дефисом.
- Строк не больше заданного числа: старые уходят за многоточие, новая фраза ярче старых.
- Облака нескольких говорящих не перекрываются: дальнее поднимается над ближним, у края экрана облако прижимается внутрь.
- Бегущие точки показывают, что игрок говорит или фраза ещё распознаётся.
- Фраза заканчивается паузой или сигналом конца речи от Plasmo Voice. Длинная речь режется в тихом месте, чтобы субтитры не ждали конца монолога.
- Тишина и шум на распознавание не отправляются. Известные «галлюцинации» Whisper («Продолжение следует…», «Субтитры сделал…», «Thank you for watching») и зацикленные повторы отбрасываются.

## Команды и клавиши

| Действие | Как |
|---|---|
| Открыть настройки | `/voicecaptions` или Mod Menu |
| Включить или выключить субтитры | `/voicecaptions toggle` или клавиша «Вкл/выкл субтитры голоса» (по умолчанию не назначена, **Настройки → Управление → Субтитры голоса**) |
| Проверить распознавание | `/voicecaptions check` |
| Состояние движка | `/voicecaptions engine` или `/voicecaptions engine status` |
| Скачать движок для видеокарты | `/voicecaptions engine install` |
| Отменить загрузку | `/voicecaptions engine cancel` |
| Показать пример облака | `/voicecaptions test [текст]` |

### Вкладка «Вид»

| Настройка | По умолчанию | Допустимо | Что делает |
|---|---|---|---|
| Ширина облака, пикс | 180 | 60–400 | ширина текста до переноса |
| Строк не больше | 3 | 1–8 | старые строки уходят за многоточие |
| Показывать, с | 4 | 1–30 | базовое время показа фразы; длинные фразы висят дольше, до 15 с |
| Дальность, блоков | 32 | 4–128 | субтитры дальних игроков не показываются |
| Размер вблизи | 1.0 | 0.5–2.0 | размер облака рядом с вами (1 — обычный текст интерфейса) |
| Размер вдали | 0.6 | 0.3–1.0 | доля размера на максимальной дальности |
| Высота над ником | 0.55 | 0–3 блока | поднимите, если облако закрывает значок Plasmo Voice |
| Непрозрачность фона | 170 | 0–255 | 0 — прозрачный, 255 — сплошной |
| Сквозь стены | вкл. | | голос слышно через стены, поэтому и субтитры видно. Выключите, чтобы видеть только игроков в прямой видимости |

## Приватность

- В режиме «Авто» речь не покидает ваш компьютер: и NPU-сервер, и движок на видеокарте работают локально.
- В режиме «Свой сервер» речь уходит только на указанный адрес.
- Ни звук, ни текст не сохраняются на диск.
- Мод ничего не отправляет на сервер Minecraft.

## Файлы и папки

- `config/voicecaptions.json` — настройки (атомарная запись, резервная копия `.bak`).
- `voicecaptions/engine/` в папке игры — скачанный whisper.cpp, модели и журнал движка `engine.log`. Открыть папку можно кнопкой «Открыть папку движка» на вкладке «Распознавание». Чтобы освободить место, удалите эту папку; при следующей установке движок скачается заново.

## Частые вопросы и проблемы

**Субтитров нет совсем.** Проверьте по порядку: стоит ли Plasmo Voice и слышите ли вы игрока; не выключены ли субтитры (`/voicecaptions toggle`); что отвечает `/voicecaptions check`; не дальше ли игрок, чем «Дальность».

**`check` пишет, что распознавать нечем.** Скачайте движок для видеокарты или запустите FastFlowLM. В режиме «Свой сервер» проверьте адрес.

**Загрузка движка не идёт.** GitHub или Hugging Face недоступны напрямую. Включите системный прокси или задайте `HTTPS_PROXY` и повторите `/voicecaptions engine install`.

**Первая фраза появляется с большой задержкой.** Это сборка шейдеров Vulkan (5–8 с) или загрузка модели на NPU (10–15 с). Мод делает первую фразу сам при входе в мир, дальше задержка небольшая.

**Распознаётся с ошибками.** Выберите модель Turbo, проверьте, что «Язык» стоит правильно (`ru` для русской речи, пусто — автоопределение).

**Субтитры отстают.** Уменьшите «Длину фразы» и «Паузу до конца фразы». Если слабая видеокарта, выберите модель Small.

**Облако закрывает значок Plasmo Voice над головой.** Увеличьте «Высоту над ником».

**После вылета игры остался процесс whisper-server.** Мод закрывает его при следующем запуске сам.

**Работает ли на Linux и macOS?** Движок для видеокарты мод скачивает только для Windows x64. На других системах используйте режим «Свой сервер».

## Сборка из исходников

Нужна JDK 25.

```powershell
git clone https://github.com/ServChan/VoiceCaptions.git
cd VoiceCaptions
.\gradlew.bat build
```

На Linux и macOS используйте `./gradlew`. Готовый файл: `build/libs/voice-captions-1.1.1.jar`.

Живая проверка движка (скачивает файлы в указанную папку, нужны `ru.wav`, `short.wav` и `en.wav` в 16 кГц моно):

```powershell
.\gradlew.bat test --tests "*LiveEngineTest" "-Dvoicecaptions.live=<папка>" "-Dvoicecaptions.live.models=base,turbo"
```
